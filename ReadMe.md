## About The Project

The project is helpful for beginners who are just entering into the field of software development.<br> The project is a full stack application based on `Fast API` framework, along with frontend covering basic to advances `Vanilla JS` with Basic `HTML` and`CSS`. The project also features basic **login/signup** authentication, followed by the `CRUD` methods (**Create, Read, Update, and Delete**) for the object/data that is displayed, additionally , it also features a **logout** option.

## What will you get from this project?

Learners would be look to take a look into how `APIs` are created, basic `Schema` for databases, additionally, they will be able to learn how to ***call APIs from JS and toggle components in the HTML through DOM*** and many more!
